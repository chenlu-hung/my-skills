# 中文 AI 腔 tell 清單

只在 **DOC** 用。CHAT 不需要逐條掃，CODE 完全不適用。

**這些是傾向，不是禁令。**判準：這個詞刪掉，句子會少講一件事嗎？會就留著。整篇零副詞、零破折號、句長一致，本身就是另一種可辨識的 AI 簽名，而且更難讀。

## 開場清喉嚨

寫的人要暖場，讀的人不用。直接講內容。

- 值得注意的是／需要指出的是／必須強調的是
- 不難發現／我們可以看到／由此可見
- 事實上／說到底／坦白說
- 在當今……的時代／背景下
- 隨著……的快速發展
- 讓我們一起來看看／接下來，我們將……
- 首先，我們需要明確一點

## 收尾套路

- 總的來說／綜上所述／總而言之／歸根結底
- 希望這對你有幫助／如有問題歡迎隨時提出
- 最後一句刻意寫成對仗金句

段落自然結束就結束。不必每節都收束。

## 強迫對仗與排比

| 樣式 | 問題 |
|---|---|
| 不僅……而且…… | 兩件事被硬綁成一組 |
| 既……又…… | 同上 |
| 不是 X，而是 Y | 二元對比，直接講 Y 就好 |
| 一方面……另一方面…… | 機械成對 |
| 三項排比（更快、更穩、更省） | 湊三個，第三個通常是灌的 |
| 首先／其次／最後 | 三段式模板，跟內容的實際結構無關 |

寫兩項比湊三項誠實。真的有四項就寫四項。

## 動詞被名詞吃掉

中文 AI 腔最重的一個 tell。動詞被拆成「虛動詞 + 名詞」。

| 寫成 | 改成 |
|---|---|
| 進行分析／進行優化／進行處理 | 分析／優化／處理 |
| 作出決定／作出判斷 | 決定／判斷 |
| 加以改善／予以修正 | 改善／修正 |
| 對 X 進行 Y 的處理 | 處理 X 的 Y |
| 起到……的作用 | 能……／會…… |
| 具有……的特性 | 是……／會…… |
| 實現了……的功能 | 會…… |

## 「性」「化」「度」堆疊

| 寫成 | 改成 |
|---|---|
| 可讀性的提升 | 更好讀 |
| 系統的穩定性與可維護性 | 系統穩、好維護 |
| 進行合理化的調整 | 調整 |
| 提高了程式碼的複用度 | 更多程式碼可以重用 |

## 「的」連發

一個名詞片語裡出現三個以上的「的」就重寫。

> 一個基於機器學習的自動化的資料清理的流程

→ 用機器學習自動清資料的流程

## 假主體

物件不會做人做的事。誰做的就寫誰。

| 寫成 | 問題 |
|---|---|
| 數據告訴我們 | 數據躺在那。是有人讀了它並下判斷。 |
| 市場會獎勵…… | 市場不獎勵誰。是買方付錢。 |
| 文化就會改變 | 文化不會自己變。是人改了行為。 |
| 問題就迎刃而解了 | 誰解的？ |
| 這個設計帶來了…… | 設計不帶來東西。是使用者因此能做某事。 |

找不到具體的人就用「你」，把讀者放進場景裡。

## 客服腔與教學腔

- 您可以透過以下方式……／建議您……
- 相信您已經注意到……
- 小提醒：／劃重點：／敲黑板
- 每一段都先粗體一個詞再解釋

技術文件裡「你」比「您」自然，除非是對外正式信件。

## 空話宣稱

沒有數字或具體事實支撐的形容詞。

- 大幅提升／顯著改善／極具價值／效果拔群
- 業界最佳實務／符合現代開發需求／面向未來
- 強大而靈活／簡單而優雅

有數字就給數字。沒有就把形容詞刪掉，留下事實。

## 排版 tell

- 每一節都恰好三個 bullet
- 每個 bullet 都以粗體詞開頭
- emoji 當小標題
- 同一段出現兩個以上破折號
- 驚嘆號
- 中英混排時空格與全形／半形標點不一致（同一份文件裡要一致）
